# High Hype

High Hype is a modern design and digital studio brand focused on strategy, branding, product thinking, and premium web experiences for founders, startups, and ambitious businesses.

This repository contains the website for High Hype, built with React, Vite, and custom front-end design systems. The project reflects the current rebrand from Soni Labs to High Hype, with a monochrome visual system, custom motion, and a polished studio identity.

## Tech stack

- React
- Vite
- GSAP
- Tailwind CSS
- React Router
- Sanity-ready content structure

## Project goals

- Present High Hype as a premium global design studio
- Position the founder brand around clarity, craft, and execution
- Showcase services, process, and work in a polished portfolio layout
- Support a minimal black-and-white aesthetic with a green brand mark

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Notes

This repo is currently set up as a Vite-based front-end portfolio and studio website and is intended for deployment to a static hosting platform such as GitHub Pages, Vercel, or Netlify.
